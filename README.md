# Ameet Kumar — Portfolio Website

A responsive single-page portfolio for Ameet Kumar, Machine Learning Engineer.

## Files
- `index.html` — website content and structure
- `styles.css` — responsive styling and visual system

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static web server.

Example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy
This is static HTML/CSS/JS and can be deployed directly to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any standard web server.
